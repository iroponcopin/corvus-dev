Novità · Versione 5.5.962

Corvus Store 5.5.962 can install Punchy!, a Fabric mod that adds first-person animations and visible hands holding items. Corvus Agent 5.5.962 changes nothing for servers, except that it never treats a client-only mod as a server mod.

Punchy! is made by its own authors, not by Corvus. Its licence does not allow Corvus to host the file, so Corvus Store downloads it straight from Modrinth, and only when you press Install. It is never installed automatically; a copy you put in your mods folder yourself counts as installed.

Punchy! is client-side only. It needs Fabric API; Corvus Store does not install Fabric API for you, and it says so if Fabric API is missing. Updates follow the version Corvus lists.

Known limits: the install was checked with a local stand-in download and tests, not yet with a real download of Punchy! through the Store, and not on Windows or Linux.

Corvus Store and Corvus Agent update themselves.

Guida

Corvus è una piccola app desktop che mantiene le tue mod aggiornate automaticamente. Controlla questo Wiki per la versione attuale, scarica gli aggiornamenti per te e verifica ogni file scaricato con un checksum SHA-256 pubblicato qui prima di toccare la tua cartella mods. Questo Wiki è l'unica fonte di cui si fida.

Questa guida è stata scritta per le versioni precedenti di Corvus. Corvus Store 3.0 ha schermate nuove, quindi alcuni passaggi possono differire.

Che cos’è Corvus e perché è nato

Tenere le mod aggiornate a mano significa tornare alla pagina di download, confrontare i numeri di versione, scaricare un nuovo file e rimetterlo nella cartella giusta a ogni rilascio. Corvus lo automatizza: legge il manifesto delle versioni di questo Wiki, lo confronta con ciò che hai già installato e scarica solo ciò che è cambiato.

Ogni download del launcher viene verificato con un checksum SHA-256 pubblicato da questo Wiki prima di essere usato. Se un file scaricato non corrisponde, il launcher non lo installa. Questo Wiki è l'unica fonte di verità del launcher su quale sia la versione «attuale».

Come installare Corvus

Corvus è disponibile dalla pagina di download di questo Wiki in due forme:

  • Installatori nativi per ciascun sistema operativo (.msi per Windows, .dmg per macOS, .deb per Linux) — si installano con la stessa procedura di una normale applicazione desktop e non richiedono Java. Non sono ancora firmati digitalmente, quindi al primo avvio il sistema operativo mostrerà un avviso. Su macOS, invece di fare doppio clic, fai clic destro sull’applicazione e scegli «Apri». Su Windows, nell’avviso di SmartScreen scegli «Ulteriori informazioni» → «Esegui comunque».
  • Il jar multipiattaforma corvus-5.5.962.jar — lo stesso identico file funziona su Windows, macOS e Linux, ma richiede che Java 25 o successivo sia già installato. Se il doppio clic non lo apre, apri un terminale (o il prompt dei comandi) nella cartella in cui l’hai scaricato ed esegui java -jar corvus-5.5.962.jar.
Indicare una cartella del pacchetto di mod già esistente

Se hai già installato le mod a mano, non devi ricominciare da capo. Al primo avvio il launcher ti lascia scegliere la cartella in cui le tue mod già si trovano, invece di crearne una nuova. Indica la tua cartella mods esistente e il launcher tratterà quell'installazione come quella che gestisce da quel momento.

Differenza tra modalità di aggiornamento automatica e manuale

Nella modalità di aggiornamento automatica il launcher controlla da sé le informazioni di pubblicazione di questo Wiki e installa le nuove versioni non appena vengono pubblicate. Senza che tu debba fare nulla, la cartella del pacchetto resta sempre aggiornata.

Nella modalità di aggiornamento manuale il launcher controlla comunque se ci sono aggiornamenti, ma aspetta la tua conferma prima di scaricare o installare qualcosa. È comoda quando vuoi scegliere tu il momento dell’aggiornamento, per esempio per evitare che si intrometta durante una partita.

Come verificare che un aggiornamento sia stato davvero applicato

Dalla versione 1.1.0 in poi, premendo Update i nuovi file delle mod vengono scritti direttamente nella cartella mods del pacchetto. La scritta «Update complete» non compare finché, dopo l’aggiornamento, il contenuto della cartella non è stato davvero ricontrollato e non si è confermato che i file attesi ci siano. Se qualcosa fallisce a metà strada, viene segnalato come errore e non come un falso successo.

Come verificarlo di persona su macOS: apri la cartella indicata nella sezione Generali (in Finder premi ⌘+⇧+G e incolla il percorso), guarda dentro mods e controlla il numero di versione contenuto in ciascun nome di file cherry-*.jar prima e dopo Update.

Se aggiorni da una cartella del pacchetto toccata per l’ultima volta da un launcher precedente alla 1.1.0, solo la prima volta può capitare che il jar della versione vecchia di quella mod resti accanto a quello nuovo (i launcher precedenti non tenevano traccia dei file che avevano collocato loro stessi). Dall’aggiornamento successivo in poi la cosa si risolve da sé. Se ti dà fastidio subito, puoi tranquillamente eliminare a mano l’cherry-*.jar con il numero di versione più vecchio, dopo aver verificato che quello nuovo sia presente.

Ripristinare da un backup quando un aggiornamento va male

Per i casi in cui l’aggiornamento lascia il pacchetto in uno stato che non vuoi, per esempio con una mod che funziona male, o in cui vuoi annullare l’aggiornamento, il launcher conserva come backup lo stato del pacchetto precedente all’aggiornamento. Invece di provare a sistemare i file a mano, usa la funzione di ripristino del launcher per riportare la cartella del pacchetto allo stato del backup.
