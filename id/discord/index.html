Cara menyiapkan

  1. 1

    1. Tambahkan bot

    Gunakan tombol di atas. Ia meminta empat hal — melihat saluran, mengirim pesan, menyematkan tautan, membaca riwayat — ditambah izin membuka satu utasan per laporan. Tidak pernah meminta izin administrator.

  2. 2

    2. Pilih saluran

    Jalankan /release channel dan pilih tujuan pengumuman. Ini menjadi saluran bawaan: semua yang tidak kamu arahkan ke tempat lain masuk ke sini.

  3. 3

    3. Pilih bahasa

    Jalankan /language set. Tersedia tiga belas bahasa, masing-masing ditulis dengan aksaranya sendiri.

  4. 4

    4. Pisahkan (opsional)

    Dengan /channels set, beri saluran tersendiri untuk pembaruan, pratinjau, laporan bug, dan permintaan. Yang tidak kamu atur tetap memakai saluran bawaan.

    updateupcomingbugrequest

Yang diposkan bot dengan sendirinya

Tiga hal, masing-masing ke salurannya sendiri jika sudah kamu atur. Tidak ada yang diposkan dua kali.

  • Sebuah rilis terbit — modpack, dan Corvus sendiri jika kamu menyalakannya.
  • Sesuatu diumumkan lebih awal, langsung dari halaman «Berikutnya».
  • Seseorang melaporkan bug atau mengajukan permintaan, lengkap dengan utasan untuk berdiskusi.

Semua perintah

/bug

Melaporkan bug dan mengikuti perkembangannya.

PerintahFungsinyaSiapa yang bisa memakai
/bug newMembuka formulir singkat: ringkasan satu baris, apa yang terjadi, dan — jika tahu — cara mengulanginya.Siapa saja
/bug list <status>Menampilkan laporan server ini, yang terbuka lebih dulu. Hanya kamu yang melihat balasannya, jadi periksa sebelum melapor ganda.Siapa saja
/bug close <number> <resolution>Menandai laporan sebagai selesai dan mencatat bagaimana diselesaikan.Kelola Server
/bug reopen <number>Mengembalikan laporan yang ditutup ke daftar, kalau ternyata belum diperbaiki.Kelola Server

/channels

Kirim tiap jenis pesan ke salurannya sendiri.

PerintahFungsinyaSiapa yang bisa memakai
/channels set <kind> <channel>Mengarahkan satu kategori — pembaruan, pratinjau, laporan bug, atau permintaan — ke saluran tertentu.Kelola Server
/channels showMenampilkan tujuan keempat kategori saat ini.Siapa saja
/channels clear <kind>Mengembalikan kategori itu ke saluran bawaan server.Kelola Server

/language

Memilih bahasa yang dipakai bot ini di server ini.

PerintahFungsinyaSiapa yang bisa memakai
/language set <language>Menetapkan bahasa. Pengumuman, formulir, dan balasan mengikutinya sejak saat itu.Kelola Server
/language showMenampilkan bahasa yang disetel untuk server ini.Siapa saja

/release

Pengumuman pembaruan modpack dan Corvus.

PerintahFungsinyaSiapa yang bisa memakai
/release channel <channel>Menetapkan saluran bawaan. Semua yang tak punya saluran sendiri masuk ke sini.Kelola Server
/release statusMenampilkan semua pengaturan server ini saat ini.Siapa saja
/release latestMenampilkan rilis terbaru yang diketahui bot, tanpa mengumumkannya ke saluran.Siapa saja
/release enableMenyalakan kembali pengumuman untuk server ini.Kelola Server
/release disableMenghentikan pengumuman tanpa mengeluarkan bot atau kehilangan pengaturan.Kelola Server
/release launcher <enabled>Memilih apakah build peluncur Corvus ikut diumumkan.Kelola Server
/release upcoming <enabled>Menyalakan atau mematikan pratinjau, dan menampilkan apa yang akan datang.Siapa saja
/release testMengirim contoh pengumuman agar kamu bisa memeriksa saluran dan izin.Kelola Server

/request

Meminta fitur atau perubahan, dan mengikuti perkembangannya.

PerintahFungsinyaSiapa yang bisa memakai
/request newMembuka formulir singkat: apa yang kamu inginkan dan mengapa itu membantu.Siapa saja
/request list <status>Menampilkan permintaan server ini, yang terbuka lebih dulu. Hanya kamu yang melihat balasannya.Siapa saja
/request close <number> <resolution>Menandai permintaan sebagai selesai dan mencatat keputusannya.Kelola Server
/request reopen <number>Mengembalikan permintaan yang ditutup ke daftar.Kelola Server

Tiga laporan sejenis per sepuluh menit, per orang, per server. Melaporkan bug tidak pernah menghalangi kamu mengajukan permintaan.

Tiga belas bahasa

Bahasa dipilih per server, bukan per orang: pengumuman masuk ke saluran bersama, jadi semua yang membacanya melihat teks yang sama. Formulir, balasan, dan pesan kesalahan mengikuti pengaturan yang sama.

Apa yang disimpan

Sebuah laporan menyimpan apa yang kamu tulis di formulir, ID pengguna Discord dan nama tampilanmu, serta tempat ia diposkan. Hanya itu. Bot tidak menyimpan riwayat pesan, tidak membaca saluran yang tidak ditunjuk untuknya, dan tidak ada kaitannya dengan akun Minecraft kamu.
