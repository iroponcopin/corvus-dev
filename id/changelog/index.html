Riwayat Pembaruan

Riwayat pembaruan Halia, OUKA, Cherry, Tsubomi, dan Aureum, serta pengumuman model yang telah berakhir. Pilih model untuk melihat apa yang berubah di setiap rilis, dari yang terbaru.

Diperbarui 2026-10-31

Angka seperti damage dan kecepatan yang ditampilkan adalah nilai bawaan (default) saat dipasang. Angka yang benar-benar terasa saat bermain bisa berbeda karena penyesuaian config di sisi server.

Tidak ada pembaruan yang cocok dengan kriteria ini.

Fitur Baru

V1.8 5567 menambahkan generasi berikutnya dari dua belas mesin, masing-masing berupa blok baru dengan gerakan dan layar baru, serta Battery Charging Socket yang semudah peti. Mesin sebelumnya tetap bekerja seperti biasa.

Perubahan (15)

  • Setiap mesin adalah blok baru dengan tampilan, gerakan, dan layar baru. Mesin sebelumnya tetap bekerja seperti biasa.
  • Stasis Harvester (generasi ke-2 Kinetic Grinder): atur area dengan penggeser (lebar 3 sampai 9). Ia membunuh 4 kali lebih cepat dan dapat mengalahkan Wither.
  • Precision Assembly Cell (generasi ke-3 jalur perakitan): dua lengan robot bekerja di atas meja putar dalam sel kaca 3 × 3 × 3. Kecepatannya 4 kali Next-Generation Assembly Line.
  • Logistics Skyport (generasi ke-2 stasiun drone): tiga drone terbang secara mandiri, masing-masing membawa 9 tumpukan dan terbang 2 kali lebih cepat. Bekerja dengan stasiun sebelumnya di kedua arah.
  • Phase Resonance Miner (generasi ke-2 penambang resonan): pilih lebar 1 sampai 9 dan kedalaman 1 sampai 32 dengan penggeser. Ia menambang 4 kali lebih cepat.
  • Molten-Salt Solar Tower (generasi ke-2 menara surya): peringkat 80,000 J/t (4 kali). Ia menyimpan panas dalam garam cair dan menghasilkan listrik di malam hari. Saat dihancurkan, panasnya tetap ada di item.
  • Tracking Heliostat (generasi ke-2 heliostat): mengikuti matahari dan mengarahkan cahaya ke menara. Bersama Molten-Salt Solar Tower, ia memberi 2 kali panas dibanding cermin sebelumnya.
  • Tachyon Overdrive (generasi ke-2 akselerator): penggeser 100 sampai 1000%, dengan konsumsi daya 25% lebih rendah.
  • Isostatic Press (generasi ke-2 penghancur): 4 kali lebih cepat.
  • Dynamo Crank (generasi ke-2 engkol tangan): roda gila berat tetap berputar sekitar 3 detik setelah Anda berhenti. Output hingga 16,000 J/t.
  • Ultracentrifuge (generasi ke-2 sentrifus): memisahkan 4 kali lebih cepat, dengan peluang 1,5 kali dan 8 slot output.
  • Atomic Lattice Crafter (generasi ke-2 auto-crafter): membuat 4 kali lebih cepat.
  • OUKA Type-W2 “Hayate” (generasi ke-2 turbin angin): tinggi sekitar 48 blok, peringkat 200,000 J/t (4 kali). Bangun berjarak 31 blok atau lebih dari turbin lain.
  • Battery Charging Socket: buka dengan tangan kosong dan pindahkan baterai seperti peti. Hopper dan pipa juga terhubung. Soket yang sudah ada tetap menyimpan isinya.
  • Kode hadiah: masukkan /ouka code OUKA-5567 di dalam game dan hadiah muncul di depan Anda. Berfungsi di survival tanpa cheat, sekali per pemain per dunia.

Catatan Penting (5)

  • Sebelum memasang V1.8 5567, hapus jar OUKA lama (1.8.3371 atau lebih lama) dari folder mods dan simpan hanya 1 salinan GeckoLib 5.5.6. Diperlukan Minecraft 26.3, Fabric Loader 0.19.5 atau lebih baru, dan Fabric API 0.161.0+26.3 atau lebih baru. Pasang di client dan server.
  • Mesin sebelumnya mempertahankan desain dan angkanya; mesin baru adalah blok terpisah.
  • Jika Next-Generation Assembly Line dihancurkan, isinya hilang; ini sudah berlaku sebelumnya dan tidak diubah di versi ini.
  • Hanya diperiksa dengan tes otomatis dan klien uji, bukan dalam permainan multipemain nyata.
  • README di dalam zip ini masih mengulang kalimat V1.7 88213 bahwa batas penyimpanan per sel telah dinaikkan. Kalimat itu keliru; lihat koreksinya di catatan V1.7 91209.

Corvus Store 4.1.0 adds one thing: Corvus Agent can be set up from the Store.

Corvus Agent is the small program that sits beside a Minecraft server you host yourself and keeps its mods in step with the Store. The Store itself never starts, stops or talks to your server.

A folder that is not a server folder is refused before anything is downloaded, and nothing is changed. Your own mods are never touched: only files matching the pack's exact naming are removed, everything is backed up first, and each removal is written to the log.

Corvus can now update itself. From this version on you should not need to visit this site again: when a new Corvus is released it downloads it, checks it against the SHA-256 published here, replaces itself and reopens. It always asks first, even with automatic updates turned on — restarting the app while you are using it is not something it should decide on its own. If anything goes wrong the previous version is put back automatically: the new build has to actually start before the old one is discarded. Two honest limitations. On Linux the .deb needs administrator rights that Corvus cannot request, so it downloads and verifies the file and then shows you the exact command to run — it does not pretend to have installed it. On Windows the update reinstalls the MSI, which means Windows will show its usual permission prompt. This release also follows the site to its new address; if you are on 1.4.0 or earlier you need to download once from here by hand, because those versions are still looking for the old address and cannot be reached.
