업데이트 기록

Halia, OUKA, Cherry, Tsubomi, Aureum의 업데이트 기록과 종료된 모델의 공지. 모델을 고르면 각 릴리스의 변경 사항을 최신순으로 볼 수 있습니다.

최종 업데이트 2026-10-30

표시된 데미지·속도 등의 수치는 도입 시점의 기본값입니다. 서버 측 config 조정에 따라 실제 플레이 체감 수치와 다를 수 있습니다.

조건에 맞는 업데이트가 없습니다.

신규 기능

V1.8 3371은 Halo Beacon, 173 TW Stellar Fusion Reactor, 100 MW Combined-Cycle Gas Turbine, Subspace Silo를 추가하며, V1.8 2033의 둥근 타워 두 개인 Echo Resonance Excavator와 Helium-3 Regolith Refinery도 포함합니다.

변경 사항 (6)

  • OUKA Halo Beacon은 OUKA Beacon의 2세대입니다. 범위는 4000 블록이며, 같은 단계에서 효과가 1.25배 강합니다. 받침대는 기존 비콘과 모양이 같지만 Max 등급 이상의 OUKA 합금 블록으로 지어야 합니다. 두 비콘이 겹치면 효과별로 더 강한 값이 적용되며, 값은 더해지지 않습니다. 기존 비콘은 변경되지 않았습니다.
  • Stellar Fusion Reactor는 3세대 인공 태양입니다. 크기는 32 × 16 × 32 블록이고 부피는 Sun V2의 4배이며, 정격은 173 TW입니다. Sun V2와 같은 중수소 및 헬륨-3 코어를 태우며, 각 코어가 지속되는 시간도 같습니다. 유리를 통해 회전하는 고리가 있는 황금빛 별이 보입니다.
  • Combined-Cycle Gas Turbine은 2세대 가스 터빈 발전기입니다. 크기는 3 × 6 × 3 블록이고 정격은 100 MW로 V1의 20배입니다. 연료 1 J마다 2 J의 전기를 생산합니다. 화면에는 출력, 상태, 남은 연료 시간이 표시됩니다. 100 MW에서는 등유 캔 하나가 약 1.2초 동안 유지됩니다.
  • Subspace Silo는 개수 제한이 없는 새로운 대형 사일로입니다. 완성된 컨트롤러를 빈손으로 한 번 터치하면 이후에는 인벤토리 옆의 둥근 버튼으로 리모컨 없이 열 수 있습니다. 개수, 이름, 최근 항목, 또는 직접 드래그한 순서로 오름차순 또는 내림차순 정렬할 수 있습니다. 기존 Quantum-Compression Vault에 연결된 PDA를 새 컨트롤러에서 사용하면 전부 옮길지 묻습니다. Move를 눌러야만 아이템이 옮겨지며, 기존 사일로는 그대로 남습니다.
  • 단독으로 출시된 적 없는 V1.8 2033이 포함됩니다. Echo Resonance Excavator(11 × 18 원형; 1 GW로 100 tick마다 에코 조각 하나를 채굴)와 Helium-3 Regolith Refinery(7 × 12 원형; End Stone 16개 또는 달 레골리스 1개를 헬륨-3 캔으로 바꿈)가 있으며, 둘 다 새로운 흰색 Resonance Casing 계열로 만들어집니다. 연료가 든 Sun V2 컨트롤러를 부수면 이제 코어가 떨어집니다. V1.8 2012도 포함됩니다.
  • 이 빌드에서 확인됨: JUnit 2404건 통과, GameTest 1556건 연속 3회 통과, 기존 월드와 새 월드에서 서버 충돌 검사 정상.

주의 사항 (4)

  • V1.8 3371을 설치하기 전에 mods 폴더에서 기존 OUKA jar(1.8.2012 이하)를 삭제하고 GeckoLib 5.5.6은 1개만 남기세요. Minecraft 26.3, Fabric Loader 0.19.5 이상, Fabric API 0.161.0+26.3 이상이 필요합니다. 클라이언트와 서버 모두에 설치하세요.
  • 미확인: 게임 밸런스. Halo Beacon의 강도, 173 TW Stellar Fusion Reactor, 연료를 매우 빠르게 쓰는 100 MW 터빈은 밸런스 테스트를 거치지 않았습니다.
  • 실제 클라이언트 검사는 59개 그룹에서 실행했고 54개가 통과했습니다. 세 그룹(Sun V1 외형, 장비 검사, 중공업 V1.6 검사)은 V1.7 1128612에서와 똑같이 실패하며 수정되지 않았습니다. 릴리스 빌드를 실행하는 동안 두 그룹이 추가로 실패했고, 단독 실행 시 통과했습니다. 패키징된 jar 자체는 서버 충돌 검사 두 가지로만 실행되었습니다.
  • 이 zip의 README에는 셀당 저장 한도가 올랐다는 V1.7 88213의 문구가 아직 남아 있습니다. 이 문구는 잘못되었습니다. V1.7 91209 노트의 정정을 참고하세요.

신규 기능

변경 사항 (1)

  • 볼트 라이플 설정의 위력과 피해량 슬라이더가 이제 사격을 바꿉니다. 이전에는 모든 사격이 기본값을 썼습니다.

주의 사항 (2)

  • 피해량은 라이플의 기본 최대치를 넘지 않고, 폭발과 충격파가 닿는 거리의 제한도 그대로이므로, 위력을 높이면 주로 겉모습이 달라집니다.
  • 테스트 서버와 테스트 클라이언트에서만 확인했으며, 실제 멀티플레이에서는 아직 시험하지 않았습니다.

신규 기능

볼트 라이플을 추가했습니다. 공식 마법진을 충전하고 목표를 표시한 뒤 쏘면, 볼트가 슬로 모션으로 날아가 착탄 지점에서 터집니다.

변경 사항 (5)

  • 새 아이템: 볼트 라이플. 오른쪽 클릭을 길게 눌러 충전하며 조준경을 들여다봅니다. 왼쪽 클릭으로 맞힐 지점이나 생물을 표시하고, 웅크리면 표시가 지워집니다.
  • 충전하는 동안 총구 앞에 공식 마법진이 겹겹이 쌓입니다. 오래 충전할수록 강한 한 발이 됩니다.
  • 놓으면 발사: 볼트가 슬로 모션으로 날아가고, 착탄 지점에 봉인이 내려앉은 뒤 터지며, 땅 위로 충격파가 퍼집니다.
  • 폭발과 충격파는 닿는 범위의 생물과 플레이어에게 피해를 줍니다. 크리에이티브·관전자 모드의 플레이어는 맞지 않습니다.
  • 엔더의 눈, 네더라이트 주괴, 쇠뇌, 망원경으로 제작하며, 전투 탭과 Halia 탭에 있습니다. 설정은 키로 엽니다(기본 H).

주의 사항 (6)

  • 서버에서는 폭발과 충격파가 닿는 거리에 제한이 있어, 보이는 것보다 짧습니다.
  • 기본 설정에서는 폭발이 블록을 부수지 않습니다. 서버 설정으로 크레이터를 허용할 수 있습니다.
  • 설정에서 고른 위력과 피해량은 서버가 허용하는 경우에만 쓰입니다. 그렇지 않으면 모든 사격이 기본값을 씁니다.
  • 공중에서 충전하면 그 자리에 머물고, 쏜 뒤에는 낙하 피해 없이 천천히 내려옵니다.
  • 쏜 사람에게는 사격 장면이 짧게 재생됩니다. 설정에서 끌 수 있습니다.
  • 테스트 서버와 테스트 클라이언트에서만 확인했으며, 실제 멀티플레이에서는 아직 시험하지 않았습니다.

Corvus now recognises the pack's own files by name, so superseded ones are removed whether or not it has a record, and it checks afterwards that only one copy of each mod is left. Your own mods are never touched: only files matching the pack's exact naming are removed, everything is backed up first, and each removal is written to the log.

Corvus can now update itself. From this version on you should not need to visit this site again: when a new Corvus is released it downloads it, checks it against the SHA-256 published here, replaces itself and reopens. It always asks first, even with automatic updates turned on — restarting the app while you are using it is not something it should decide on its own. If anything goes wrong the previous version is put back automatically: the new build has to actually start before the old one is discarded. Two honest limitations. On Linux the .deb needs administrator rights that Corvus cannot request, so it downloads and verifies the file and then shows you the exact command to run — it does not pretend to have installed it. On Windows the update reinstalls the MSI, which means Windows will show its usual permission prompt.
