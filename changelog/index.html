更新履歴

OUKA・Cherry・Aureum・ASTRAEA・Tsubomi・Halia の更新履歴と、Alpha の終了のお知らせ。モデルを選ぶと、各リリースの変更点を新しい順に見られます。

最終更新 2026-10-16

表示されているダメージ・速度などの数値は導入時点の既定値です。サーバー側の config 調整により、実際にプレイして体感する数値とは異なる場合があります。

条件に一致する更新はありません。

新機能

工業の使い勝手を良くする更新で、1.6.2.1 の修正も含みます。触媒熱化学溶鉱炉は掘ったままの鉱石を焼けるようになり、高精度オートメーション組立ラインには先に材料を入れておける枠が付き、新しい手回し発電機でサバイバルだけの世界でも OUKA の電気を起こせます。新しいブロックを 1 つ足しました。

変更点 (4)

  • 触媒熱化学溶鉱炉は、タングステン原石と古代の残骸を、粉にせずそのまま受け取ります。燃料はアルゴンの缶で、専用の燃料の枠に入れます。ホッパーからの燃料も、その枠にだけ入ります。
  • 高精度オートメーション組立ラインに「材料」のタブが付きました。持ち物から材料の枠へ部品を入れておき、あとで製品を選ぶと、そろっていればすぐに作り始めます。一覧の緑の線は、いまの材料だけで作れる製品のしるしです。ホッパーとコンベアは、これまでどおり入口へ入れます。
  • 手回し発電機は、バニラの品だけで作れます。右クリックを押し続けるとハンドルが回り、近くのテスラ鉄塔へ電気を送ります。ハードコアの世界でも、最初の機械を動かせます。
  • 1.6.2.1 から: 桜花の加護の効果アイコンは残り、持ち物の画面でアイコンにカーソルを合わせると、受けている加護とその強さが一覧で出ます。流星は、置き方や使い方が違うときに理由を伝え、運転のヒントを出し、次の駅に止まれないときは乗っている人にその理由を知らせます。

注意点 (2)

  • 遊んだあとで前の版に戻すと、手回し発電機がワールドから消えます。
  • 1.6.2.2 を入れる前に、古い OUKA の jar(1.6.2 以前)を mods フォルダーから消し、GeckoLib 5.5.6 は一つだけ残してください。Minecraft 26.3、Fabric Loader 0.19.5 以上、Fabric API 0.161.0+26.3 以上が必要です。クライアントとサーバーの両方に入れてください。

不具合修正

Halia V1.2.1 は、OUKA と一緒に入れているとき、クリエイティブモードでインベントリを開くとゲームが落ちる不具合を直します。

変更点 (1)

  • 修正：OUKA と Halia を一緒に入れていても、クリエイティブモードでインベントリを開いたときにゲームが落ちなくなりました。Aerie のクリエイティブタブに鷲巣の心核が二重に並んでいたのが原因です。

注意点 (1)

  • 動作環境は V1.2.0 と同じです：Minecraft 26.3、Fabric Loader 0.19.5 以上、Fabric API 0.161.0+26.3 以上、Java 25。ほかの変更はありません。

新機能

Halia V1.2 は、収納ネットワーク「Aerie（鷲巣）」を追加します。鷲巣の心核と導索、セルで組み立て、持っているアイテムと流体のすべてを 1 つの端末から検索できます。鉤爪の取込口と送出口で出し入れし、自動工匠が必要なときにクラフトします。Halia Blade には、銘のある刀 20 本と技 7 種、そして刀が集めて使う「魂」が加わりました。

変更点 (8)

  • Aerie：鷲巣の心核を置き、鷲巣の導索で機械をつなぎ、抱卵庫に抱卵セルを入れ、止まり木の端末を開くと、収納したものをすべて見て検索できます。機械は 37 種類あり、多くは 16 色あります。
  • 搬入出とクラフト：鉤爪の取込口と送出口が、Aerie とチェストや機械の間でアイテムと流体を運びます。自動工匠は、書記の端末で書いた手順から必要なときにクラフトします。上昇気流の柱と野外の端末を使えば、線でつながなくても Aerie に届きます。
  • OUKA との電力連携：OUKA が入っていると、鷲巣の心核は OUKA のテスラ鉄塔の電力網から電力を受け取ります。OUKA が無ければ、Aerie は電力なしで動きます。
  • 銘のある刀 20 本：疾風牙と嵐牙の系統、鉄嶺、灰巌、木からネザライトまでの鷲羽 6 種、風化した刀、宵闇、樫芯、猛禽。多くは材料箱を使って金床で打ち、一部はボスが落とし、ゾンビが風化した刀を持っていることもあります。銘の無い刀を刀掛けに置いてウィザーの爆発に巻き込むと、灰巌に変わります。
  • 新しい技 7 種：花終、虚空斬、円月斬、縦のドライブ、横のドライブ、波刃、刺突。ドライブは斬撃を前方へ飛ばします。
  • 魂：刀を手に持って敵を倒すと、その経験値から刀に魂が集まります。召喚剣は、経験値ではなく魂を使うようになりました。金床で刀を強化すると、刀に魂が入ります。
  • 耐久と強化：銘のある刀は、それぞれ固有の耐久値を持つようになりました。強化すると、刀のダメージと最大耐久値が上がります（強化値は 200 まで）。
  • Stellar Remote SS-05 テッセラクト：専用の映像つきの、5 つ目の攻撃です。照準のまわりに一辺 640 ブロックの光の立方体が立ち上がり、地面がセルに切り分けられ、中心から外へ 1 周ずつ持ち上げられ、回され、空中に吊られ、そして空には光の立方体が固定されます。

注意点 (5)

  • 動作環境：Minecraft 26.3、Fabric Loader 0.19.5 以上、Fabric API 0.161.0+26.3 以上、Java 25。マルチプレイでは、サーバーにも Halia が必要です。
  • V1.1 の刀からの変更：同じ基礎値なら、刀の 1 撃のダメージはこれまでより 1 低くなります。新しく作る銘刀は、V1.1 より基礎攻撃力と耐久値が低くなります（例：大和は攻撃 9 → 7、耐久 100 → 40）。召喚剣には魂が必要です。すでにワールドにある刀の耐久値は、作ったときのままです。
  • OUKA が入っている場合、鷲巣の心核が電力の通った鉄塔の届く範囲に入るまで、Aerie は動きません。OUKA と一緒に電力なしで使うには、config/halia-aerie.json の powerFromOukaGrid を false にしてください。
  • V1.1 のワールドはそのまま開けます。Aerie の機械や新しい刀のあるワールドを 1.1 に戻さないでください。それらが消えます。
  • Stellar Remote は世界の広い範囲を元に戻せない形で破壊し、SS-05 は一辺 640 ブロックの範囲を一度に作り変えます。ワールドをバックアップしてください。波が通るときに立方体の中にいると死にます。

新機能

列車の更新です。流星の測量器で結んだ導線の上を、停止コイルと運行指令盤のある駅のあいだで走る列車が加わりました。新しい品 6 つと、新しいブロック 3 つを足しました。

変更点 (4)

  • 流星の測量器で、ガイドウェイの節点を順に結びます。つながった線の長さ・いちばん急な曲がり・線の上の速さを知らせ、列車が通れない曲がりや坂は結べません。
  • 線の近くに停止コイルを置くと駅になります。近くに運行指令盤を置き、編成票を使うと、その駅に列車が置かれ、駅のあいだの往復運転を始められます。
  • 四つの車両でできた列車に、座席に座って乗れます。走っているあいだも車内の通路を歩けます。扉は、止まっていて停止位置にいるときだけ開きます。
  • 先頭車の運転台で、速さ・インバータの周波数・架線の電圧を読めます。前に物があると列車は止まって待ち、ブロックは壊しません。

注意点 (2)

  • この版には給電ブロックと電力網はまだありません。運転台の電圧と周波数は見た目の飾りです。流星を入れたあとで前の版に戻すと、流星の品とブロックがワールドから消えます。
  • 1.6.2 を入れる前に、古い OUKA の jar を mods フォルダーから消し、GeckoLib 5.5.6 は一つだけ残してください。Minecraft 26.3、Fabric Loader 0.19.5 以上、Fabric API 0.161.0+26.3 以上が必要です。クライアントとサーバーの両方に入れてください。

新機能

霊脈機関の版です。銀の祭刀で霊脈を開き、幻刃の雨・霊眼・結界の印を使えるようになります。新しい品 4 つと、結界の印のブロック 1 つを足しました。

変更点 (4)

  • 銀の祭刀を組立ラインで作り、しゃがんで使うと血の儀を行います。少しの体力を払って霊脈を開きます。体力が少ないときは断られ、死にません。
  • 地紋の焦点を主の手に持ち、幻刃の雨(既定の J を押し続ける)を使うと、幻刃が視線の先へ飛び、刺さり、少し遅れて爆ぜます。幻刃はブロックを壊しません。
  • 霊眼のレンズを右クリックで覗き、霊眼の切り替え(既定の U)で静止の霊眼と看破の霊眼を替えます。看破は、OUKA の銃と幻刃の弱点への一撃を強めます。
  • 結界の白墨で、ブロックの上に結界の印を描き、地紋の焦点で霊力を注ぐと、警報・吸命・遮断の結界が立ちます。霊脈の状態は既定の I で見られます。

注意点 (2)

  • 結界は人を閉じ込めず、ブロックも守りません。遮断結界は、外から飛んでくる飛び道具と爆発の傷を止めます。吸命結界は、登録していない人からも体力を吸います。
  • 1.6.1 を入れる前に、古い OUKA の jar を mods フォルダーから消し、GeckoLib 5.5.6 は一つだけ残してください。Minecraft 26.3、Fabric Loader 0.19.5 以上、Fabric API 0.161.0+26.3 以上が必要です。クライアントとサーバーの両方に入れてください。

新機能

防衛の 25 種類すべてを、実物の大きさで作り直しました。高さ 8 ブロックのミサイルサイロとそこに立つミサイル、旋回台に載った迎撃ミサイル砲台、状態に合わせて動き光る機器、そして身に着けると立体で見える装備・ゴーグル・マスクです。これまでどおり OUKA 1.4.0 以上が必要です。

変更点 (5)

  • 一体で置く 3 つのプラント: ミサイルサイロ 3×3×8(発射台・整備塔・高さ 7 ブロックのミサイル。飛んでいる間は発射台から消えます)・迎撃ミサイル砲台 3×3×3・ガス除去装置 2×1×2。発射と空の確認は、サイロの上端の中央から行います。
  • 8 つの機器が状態を見せます: 警報中は警報ストロボの反射鏡がランプの周りを回り、収容セル監視装置は赤く点滅します。暗証キーパッドと網膜スキャナーはドアを開けている間は緑に光り、作動中のクレイモアはランプが点滅して作動線が見え、トラバサミは捕らえたものに顎を閉じ、開いたガス缶からはガスが噴き出します。
  • 有刺鉄線は杭と鉄線の柵に、毒スパイクピットは毒の杭が並ぶ穴に、収容隔壁は鋲と警告帯の付いた壁に、防護シールド壁は透ける六角形の光に、高熱切断レーザーとシールド投射機は向けた方を向く装置になりました。
  • 装備に姿が付きました: 戦術ヘルメット・ベスト・レギンス・ブーツ、レンズが光る暗視ゴーグル、密閉マスクは、身に着けると体から立体で張り出し、体の動きに合わせて動きます。手に持っても同じ姿です。
  • 迎撃ミサイルと照準タブレットは手に持つと立体で見え、3 つのプラントは Shift を押すと大きさと必要な広さが出ます。

注意点 (2)

  • V1.5.3 の世界にすでに置いてあった防衛のブロックは、壊して置き直してください(中身は落ちます)。置き直すまでは、正しく描かれず、働かないことがあります。
  • 警報ストロボ・クレイモア・トラバサミ・2 種類のガス缶は、ピストンで押せなくなりました。今回の配信に新しい音はありません。284 個の残りは V1.5.5 から V1.5.9 で順に届けます。

新機能

物流と家の 21 種類すべてを、実物の大きさで作り直しました。高さ 3 ブロックの造幣機、背丈ほどの ATM と冷蔵庫、周りを歩ける圧縮機、そして働いている間は動いて光り、部屋を照らす 1 ブロックの機器です。V1.5.2 と同じく OUKA 1.4.0 以上が必要です。

変更点 (5)

  • 一体で置く 7 つのプラント: 造幣機 2×2×3・ATM 1×1×2・スクリプトリア活版印刷機 2×1×2・蔵書棚 1×1×2・冷蔵庫 1×1×2・圧縮機 2×2×2・ロックダウン制御盤 2×1×1。空いた場所でアイテムを使うと、置いた人の方を向いて建ちます。どこを使っても同じで、どこを壊しても全体が 1 つのアイテムに戻ります。
  • 動きます: 造幣機ははずみ車が振れて打刻し、印刷機は圧盤の下で紙を刷り、蔵書棚は収めた本が見え、圧縮機は燃料が燃えている間はずみ車と圧力計が動き、制御盤はロックダウン中にランプが赤くなります。
  • 姿を持つ 1 ブロックの機器 7 つ: 水が流れる蛇口、窓が光りランプが進み具合を示す電子レンジ、回る天井ファン(レッドストーン信号で止まります)、ガラス管の中をカプセルが走る送出機と受取機、蓋が持ち上がる安全弁、着陸灯の付いたドローンパッド。働いている間は周りを照らします。
  • 配達ドローンは 4 つのローターで飛ぶ機体になりました。脚と航行灯があり、カプセルを下に吊り、進む方を向きます。
  • 水道管は管の形に、気送管は真鍮の継ぎ手付きに、展示ケースは真鍮の枠付きに、ホログラム看板は投影機に、磁気浮上コンベアは軌道になりました。金貨と紙幣は手に持つと立体で見えます。7 つのプラントは、Shift を押すと大きさと必要な広さが出ます。

注意点 (2)

  • V1.5.2 の世界にすでに置いてあった物流と家のブロックは、壊して置き直してください(中身は落ちます)。置き直すまでは、正しく描かれず、働かないことがあります。
  • レッドストーン信号で止めた天井ファンは、ガスを払わなくなりました。今回の配信に新しい音はありません(これらの機器は、ゲーム本来の音を使っています)。284 個の残りは V1.5.4 から V1.5.9 で順に届けます。

新機能

Cherry の拠点防衛と移動手段の更新です。村に衛兵村人が常駐し、セキュリティ端末と警備ロボットが自分の拠点を守り、自動タレットは据えた Cherry の銃をそのまま撃ち、ガラスのエレベーター・大型カーゴエレベーター・エスカレーターが人と荷物と乗り物を運びます。ロボット、端末、タレット、2 種のエレベーターは電力で動きます。電力はレッドストーン信号から、または OUKA V1.2 以降を導入している場合は OUKA の電力網から得られます。

変更点 (9)

  • 衛兵村人: 鐘・ベッド・村人のそろった村にプレイヤーが初めて近づくと、衛兵が 2 人(ベッド 10 台以上で 3 人、20 台以上で 4 人)配置されます。ハルバード、クロスボウ、盾を持ち、16 ブロック以内の敵対モブと戦い、クリーパーからは下がって離れた所から撃ちます。村が定員を下回っている間は 5 分ごとに 1 人補充されます。
  • 衛兵が襲うのは、村人か衛兵を傷つけたプレイヤーだけで、最後の加害から 2 分で手を引きます。衛兵どうし、村人、ゴーレムとは戦わず、ピースフルではプレイヤーに向かいません。
  • セキュリティ端末と警備ロボット: 端末を置いた人が管理者になり、右クリックで 2.5 ブロック以内のいちばん近いプレイヤーを登録します。端末につながった警備ロボットは持ち場から 12 ブロック以内を巡回し、16 ブロック以内に見えた未登録のプレイヤーにサイレンで警告して 2 秒待ち、その後 1.5 秒ごとにスタンライフルを撃ちます(ダメージ 2、スタン 3 秒)。登録済みのプレイヤー、衛兵、クリエイティブ・スペクテイターのプレイヤーは撃たれません。
  • ロボットのスタンライフルは 400 kJ のバッテリー(20 発ぶん)で動きます。端末にエネルギーがあるあいだ、端末から 16 ブロック以内で充電され、端末自身は隣のレッドストーン信号で満たされます。空のロボットもサイレンと照準はしますが、充電されるまで撃ちません。OUKA V1.2 以降を導入している場合は、OUKA のパイロンの届く範囲にあるロボットや端末は OUKA の電力網からも充電されます。

Fixes a bug that could leave your Minecraft unable to start. If you installed the mod pack by hand before pointing Corvus at the folder — which the guide tells you is fine — the first update added the new mod files but could not remove the old ones, because it had no record of what was already there. Two copies of the same mod stops the game loading. Corvus now recognises the pack's own files by name, so superseded ones are removed whether or not it has a record, and it checks afterwards that only one copy of each mod is left. Your own mods are never touched: only files matching the pack's exact naming are removed, everything is backed up first, and each removal is written to the log.

Corvus can now update itself. From this version on you should not need to visit this site again: when a new Corvus is released it downloads it, checks it against the SHA-256 published here, replaces itself and reopens. It always asks first, even with automatic updates turned on — restarting the app while you are using it is not something it should decide on its own. If anything goes wrong the previous version is put back automatically: the new build has to actually start before the old one is discarded. Two honest limitations. On Linux the .deb needs administrator rights that Corvus cannot request, so it downloads and verifies the file and then shows you the exact command to run — it does not pretend to have installed it. On Windows the update reinstalls the MSI, which means Windows will show its usual permission prompt. This release also follows the site to its new address; if you are on 1.4.0 or earlier you need to download once from here by hand, because those versions are still looking for the old address and cannot be reached.
