31:T433,Corvus Agent is the small program that sits beside a Minecraft server you host yourself and keeps its mods in step with the Store. Until now it was a zip from the website and a command typed in a terminal. It is now the last entry on the Store's shelf. Press GET and choose your server folder: the Store downloads the agent, checks its size and SHA-256 against the site, puts it in that folder as corvus-agent.jar, and writes its configuration and two start scripts (start-with-corvus.bat, and .sh for Linux and macOS). It looks in the folder's mods and lists the Corvus mods it finds there, and it reads your server's own start command from the .bat or .sh you already use, so there is nothing to edit by hand.
