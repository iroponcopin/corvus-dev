OUKA、Cherry、Aureum、ASTRAEA 和 Tsubomi 的更新记录，以及 Alpha 终止的公告。选择一个型号，按从新到旧查看每个版本的变化。

新功能

在 V1.0 与 V1.1 之上新增四十九个系统：9 × 9 合成台及其护甲，前往月球与火星的火箭，战争机械与可调校的车辆，裂变电站，精炼厂，气动管道与无人机，神话级 Boss，一百件家具，以及一本能告诉你任何物品由什么构成的 Codex。

更新内容 (5)

  • Oracle Crucible 与 Zenith 装备：9 × 9 合成台和 Core Press 可制作 Zenith 护甲与 Zenith Cutter。七个饰品栏位（H）可放置戒指、项链、腰带、护符、披风以及 Sovereign Crown。
  • 宇宙前沿：Apex Rocket 可飞往 Orbital Station、月球与火星。这些世界没有空气、重力较低；Life-Support Unit 可为密封房间充入空气，岩石中则含有铁、铜和金矿。
  • 机械：装甲车与双翼飞机；可安装引擎、轮胎和冲撞保险杠、用于牵引矿车的底盘；裂变电站；四阶段精炼厂（一个矿石炼出五个锭）；航空管道，以及在平台之间运送货物的压力无人机。
  • Codex of Creation：游戏中的每件物品都在一个可搜索的界面里；选中任一物品，即可看到它由什么构成的树状图，直至原材料。三位神话级 Boss（Steel Guardian、Sunlit Chieftain 和 Frostfield Behemoth）各自以其印记召唤；每个招式在落下之前，都会先在地面和身体上显示出来，并且每位 Boss 会在三个阶段中变得更加凶猛。
  • Celestial Blade Engine V2「Kamui」：在风格等级 SSS 时收刀，12 格内的所有敌人会被定住，然后被斩九次。Plasma Saber 现在会像镜子一样将射击物弹回；手持火把或点亮的 Saber 会照亮你周围的地面。

注意事项 (2)

  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高版本、Fabric API 0.161.0+26.3 或更高版本以及 Java 25。OUKA 为可选。已与 Cherry 1.2.0 和 OUKA 1.3.1 一同测试；不支持与 Alpha 同时安装。每个系统及十九项便利功能都可以在 config/astraea-sovereign.json 中单独关闭。
  • 本版本未包含：身体不会在关节处弯曲（只会倾斜、跳跃和下落）；手持光源不会照亮生物，也没有水面反射和法线贴图；活塞不会移动箱子。另已修复：第一人称视角下，Celestial Blade 与 Muramasa 不再显示第二把剑；爆炸时方块现在遵循其掉落规则。

新功能

Tsubomi V1.1 新增 100 种建筑方块，分为 5 个系列、每系列 20 种：樱晶、灵木、白瓷、机巧与神域。

更新内容 (6)

  • 新增 100 种方块，分为 5 个系列、每系列 20 种：晶体与琥珀、灵木与红竹、白瓷与硬玉、机巧与黄铜、神域与祭仪。所有方块都可以合成。
  • 樱晶：母岩樱晶会长出晶芽，从小到中到大，最后成为晶簇；樱晶灯用红石点亮；共鸣核每次通电只响一次。
  • 灵木是一套不会燃烧的木材，有楼梯、台阶、栅栏、栅栏门、门、活板门、压力板和按钮，可以用斧头去皮。红竹和竹子一样会燃烧。
  • 机巧：铜外壳会像铜一样氧化，管道会彼此连接，压力计把收到的最强红石信号输出给比较器，机巧门和活板门可以用手开关。
  • 神域：灯笼、能传很远的钟、让上方植物长得更快的圣土、几乎无声的地毯、可打开合成格的织机、重生锚，以及信号随昼夜和月相变化的天体仪。
  • 对服务器很轻：没有任何方块拥有方块实体或计时器。只有母岩樱晶、树叶、铜外壳和圣土会接受随机刻，而且只在生长、枯萎或氧化时。

注意事项 (2)

  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高、Fabric API 0.161.0+26.3 或更高以及 Java 25。不需要其他模组；Cherry 是可选的。
  • Tsubomi 不能与 Alpha 同时使用。只要安装了任何一个 Alpha 模组，游戏就无法启动；请先移除 Alpha 的 jar。

新功能

OUKA GUN MAX 到来：15 把枪使用 6 种弹药，每把都有自己的后坐力、换弹和声音，瞄具与配件在安装界面中装上。此外还有高 35 格的 Type-W1 “Fujin” 风力发电机、7 种颜色的 Operating Shelter 玻璃，以及新的动画运行时 OKE：它驱动枪械和风力发电机，现在还负责绘制物质收发器。所有新声音都是从零合成的。

更新内容 (8)

  • 15 把枪，从 Type-01 “Kusanagi” 卡宾枪到 Type-50 “Susanoo” 反器材炮。每把枪都有自己的操控手感、后坐力弹簧、换弹和声音。
  • 弹药共 6 种。射击在 50 格内瞬间命中；更远处，子弹边下坠边飞行。子弹会穿过木门、玻璃和铁栏杆，同时损失威力，并且从不破坏方块。
  • 4 种瞄具（反射式、全息式、2-4 倍可变倍率镜和热成像瞄具）与 10 种功能配件（枪口装置、握把、3 种弹匣、枪托和激光）会改变后坐力、声音、弹匣容量和瞄准时间。在 Z 键界面中装配，可对比枪械数值装配前后的变化。
  • 左键射击，右键瞄准，R 换弹，F 检视手中的枪，N 切换弹药或为狙击枪充能，B 切换射击模式，K 调整瞄准镜倍率，疾跑后潜行即可滑铲。所有枪械按键都可以在“OUKA GUN MAX”分类中修改。
  • 所有枪声都是从零合成的，每次射击分为 4 层（机械声、枪声、混响尾音和超音速爆裂声），混响会随你身处旷野、峡谷还是室内而变化。
  • Type-W1 “Fujin” 风力发电机由一件物品立起 35 格高，转向迎风，并按 OUKA 电网的需求调整桨叶角度，最高输出 1.0 MW。Minecraft 本身没有风，所以 OUKA 根据世界种子、时间和天气算出风。
  • Operating Shelter 玻璃有 7 种颜色。只有管理员能放置或破坏，它能承受所有爆炸，子弹也无法穿过。Operating Shelter 方块换上了装甲外观和指示灯：管理员看到绿色，其他人看到红色。玻璃不在创造模式物品栏中，需用 /give 发放。
  • 新的动画运行时 OKE 驱动枪械和风力发电机，现在也负责绘制物质收发器。本版本同时包含 V1.3.1 的修复。

注意事项 (4)

  • V1.4.0 的已知限制：目前只有物质收发器运行在 OKE 上（其他机器将在 V1.4.x 中陆续迁移）；全息配件界面与安装动画将在 V1.4.x 中加入；风力发电机只在主世界运转。新增的 /ouka reload 与 /ouka mount 命令仅限管理员使用。
  • 从之前的版本更新时，请从 mods 文件夹中删除旧的 OUKA jar（ouka-1.3.1+mc26.3.jar 等）。同时存在 2 个 OUKA jar 时，游戏将无法启动。
  • 也可以通过 Corvus Store 安装：首次请在 Corvus Store 中点击“获取”；之后 Corvus Store 会自动替换为新版本。如果你关闭了“自动更新”，请点击“更新”。（手动安装请前往 OUKA 页面。）
  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高、Fabric API 0.161.0+26.3 或更高、GeckoLib 5.5.6（已包含在 zip 中）以及 Java 25。

新功能

由 OUKA 电网供电的安防设备——激光、摄像头，以及显示其实时画面的 Corvus Book Pro——还有 Plasma Saber，以及两把无法合成的剑：需要亲手从基座上拔出的 Excalibur 与 Muramasa。

更新内容 (5)

  • Security Laser：不可见的绊线，会发出红石信号并报警；或是深红色的致命光束（每秒 10 点伤害）。Optical Prism 可将光束转折 90°，组成光栅。它不会伤害主人及主人信任的玩家，也不会破坏方块。
  • Security Camera 与 Corvus Book Pro：摄像头会追踪移动的目标；笔记本上的 CorvusOS 显示每个已绑定摄像头的真实画面，可转动摄像头、切换夜视与热成像、绘制 OUKA 电力曲线、切换激光模式、一键上锁/解锁电子锁，并编辑信任名单。
  • Plasma Saber：使用即可点亮光刃；转动和挥动越快，嗡鸣越高。在弹射物命中前挥动，箭、三叉戟或火球会被打回射击者。六种 Saber Crystal 可在 Diamond Polishing Bench 上更换颜色。
  • Excalibur：将 Hallowed Anvil Pedestal 放在 Y 180 及以上、正午且上方无遮挡的地方，按住使用键三秒将其拔出。按住后松开可释放 Excalibur Ray（50 格长、5 格宽，会被墙壁阻挡）；持剑时，你和你信任的玩家获得生命恢复 II 与抗性提升 II。
  • Muramasa：将 Blood-Bound Shrine 放在 Y 0 及以下的黑暗处；拔出它要付出一半的最大生命值。操作与 Celestial Blade 相同，会将造成伤害的五分之一转化为生命，收刀时的斩击无视护甲。

注意事项 (2)

  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高版本、Fabric API 0.161.0+26.3 或更高版本以及 Java 25。OUKA 1.3.1 或更高版本为可选：安装后，设备在 Tesla Pylon 64 格范围内取电；未安装时设备始终通电。
  • 已与 Cherry 1.2.0 和 OUKA 1.3.1 一同测试。不支持与 Alpha 同时安装。摄像头只有位于你已加载的区域内时才会显示画面。

新功能

Tsubomi V1.0.1 让传送电梯作为 Tsubomi 的方块回归：竖直叠放，跳跃上行，潜行下行。

更新内容 (3)

  • 传送电梯（新方块）：竖直放置两个或更多；在上面跳跃会升到上方的下一个，潜行会降到下方的下一个，最远 64 格。
  • 配方：6 个铜石英锭、1 个末影珍珠和 1 个红石可合成 2 个电梯。
  • 对服务器很轻：电梯是普通方块，没有方块实体也没有计时器，无人乘坐时不消耗任何资源；目的地被堵住时不会传送，旁观者不会被带走。

注意事项 (2)

  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高、Fabric API 0.161.0+26.3 或更高以及 Java 25。不需要其他模组；Cherry 是可选的。
  • Tsubomi 不能与 Alpha 同时使用。只要安装了任何一个 Alpha 模组，游戏就无法启动；请先移除 Alpha 的 jar。

新功能

更新内容 (3)

  • 仓库未搭建完成时，提示中还会另外列出最多 6 处不符合的位置（以前只列出第 1 处）。

注意事项 (3)

  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高、Fabric API 0.161.0+26.3 或更高、GeckoLib 5.5.6（已包含在 zip 中）以及 Java 25。

新功能

ASTRAEA 首次发布：五扇像机器一样开启的防爆门，三种锁与手持撬锁，五件超越下界合金的 Celestial 工具，以及 Celestial Blade —— 拔刀、斩击、格挡、收刀，还有星光幻影剑、风格评级与灵魂锻炉。

更新内容 (8)

  • 五扇防爆门（3×3 与 2×3），用手或红石开启：六片刃叶螺旋收拢的光圈门、液压双开大门、激光栅格舱门、在一阵蒸汽中破封的低温门，以及三道圆环对齐后屏障化作光芒消散的星盘之门。
  • 三种锁，可装在门、活板门、栅栏门、箱子和木桶上：配有专属编号钥匙的挂锁、4 位密码且错误后锁定时间成倍增加至 5 分钟的密码锁，以及只放行已登记的人和钥匙卡的生物识别锁。上锁的方块只有主人能破坏，红石和漏斗都无法通过。
  • 手持撬锁：左手持张力扳手，右手持撬锁针。凭咔哒声寻找角度；硬转转不动的锁芯，撬锁针会弯曲并折断。
  • Celestial 合金与耐久 4,500 的五件工具：可切换 1×1、3×3、5×5（V）挖掘并直接收入背包的镐、整棵砍倒树木并能击破盾牌的斧、将 5×5 铲平的锹、耕作并收获 5×5 的锄，以及能冲刺并投出光之枪的长枪。
  • Celestial Blade：攻击即拔刀斩击 —— 地面四连斩，空中三连斩加下劈；使用即格挡；静止不动便会收刀，被斩过的敌人都会在原地再被斩三次。大招会沿一条线劈开屏幕。
  • 星光幻影剑：用 V 或鼠标中键锁定目标，八柄光之剑随你的斩击飞出；R 发动 Spiral Drive 与 Blistering Rain。
  • 从 D 到 SSS 的风格评级。达到 SSS 时触发君主觉醒：刀速 ×1.5、移动速度 +30%、攻击速度 +50%、所受伤害减半。
  • Celestial Forge：每次击败敌人，灵魂能量都会流入刀中。在锻造台可以修复、最多淬炼 20 次（每级 +2.5%，第 20 次成为名刀），并在 50、200、500 次击败时解锁三种秘技。

注意事项 (3)

  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高、Fabric API 0.161.0+26.3 或更高，以及 Java 25。不需要其他模组。
  • 已确认可与 Cherry 1.2.0 一起运行。不支持与 Alpha 同时安装。
  • /astraeabench 可测量同时绘制 32 柄幻影剑并每秒一次空间斩时的帧率。

新功能

Tsubomi 首个版本：带着内容物搬运的木制智能箱、重力小滑槽、桌面盆景、草药茶、工具袋、黄铜手提灯和铜石英工具——而且不带来任何沉重的负担：没有任何一个方块会一直在计算。

更新内容 (9)

  • 木制智能箱：36 格，打碎后连同内容物一起变成物品，可以搬运。像木桶一样开合，红石比较器可以读取。箱子里放不进箱子；掉落的箱子物品被火、岩浆或爆炸毁掉时，内容物会散落而不会消失。
  • 重力小滑槽：最多纵向叠 128 个，从顶部放入的东西会立刻到达底部。它接收漏斗、投掷器和掉进来的物品实体，交给下方的容器，下方没有东西就丢下。它没有方块实体，也从不 tick。
  • 盆景盆：种下橡树或樱花树苗，它会分阶段生长，长成后偶尔掉落少量树叶、花瓣或树液（4 个树液合成 1 个黏液球）。
  • 草药茶：把树叶或花瓣放在营火上烤成茶叶，再与水瓶合成。获得 45 秒的速度 I，以及作为余香的 30 秒跳跃提升 I，喝完留下空瓶。
  • 冒险者工具袋：最多收纳 9 组火把、镐和铲。按 V（可改键）让选中的快捷栏格子与工具袋依次交换，有 3 tick 的短暂冷却；在物品栏中可像收纳袋一样操作。
  • 黄铜手提灯：拿在副手，亮度 12 的柔和光线会跟着你的眼睛走，不会留下光源。
  • 铜石英：2 个铜锭 + 1 个石英合成 2 个铜石英锭。镐、斧、铲、锄、剑的耐久为 640，挖掘速度 6.5，挖掘等级与铁相同，可用铜石英锭修理。
  • 安装 Cherry 后，铜石英可以代替铁用于 Cherry 的隔热衬里和推进剂罐配方（数据包，默认开启，可在数据包界面关闭）。Cherry 自己的配方仍然可用。
  • 没有沉重的负担：静止摆放的 1024 个箱子和滑槽不会给每个 tick 增加任何消耗，通过 1024 条线路搬运所需的处理量约为原版漏斗同样搬运的百分之一。

注意事项 (3)

The first install only ever happens when you press Download: Corvus fetches the Cherry package, checks its size and SHA-256, unpacks it into a temporary folder, checks every jar inside against the manifest — its size, SHA-256, mod id and version — and only then puts Cherry and the GeckoLib it needs into your mods folder, all together or not at all; if anything fails, the folder is put back exactly as it was. After that — and also for a Cherry you put in your mods folder yourself — new Cherry versions install automatically, even when Install updates automatically is off; that switch still governs the pack, the app and Aureum. GeckoLib is never downgraded: a copy that is already the same version or newer is kept. A package that carries a jar the manifest does not list, or another product's jar such as Aureum, is refused whole.

Installs into the mods folder now take turns: Cherry's and Aureum's installers share one lock, the Update pane never runs a pack update and a Cherry install at the same time, and quitting to apply a launcher update waits up to a minute for a running install to finish. The manifest's new cherry section is read leniently: if anything in it is wrong, Cherry is shown as not published and a line goes to the Log, while the pack and the app still update as before.

Verified by installing the real Cherry V1.0.0 package, from the manifest the website builds from that package, through this version's own code: both jars arrived byte for byte with nothing left behind, and the same manifest with one wrong digit in the package's SHA-256 was refused before anything was written. Not yet seen: the Download and Update buttons against the live website, and an automatic Cherry update actually running. The window itself is now glass. On macOS Corvus puts AppKit's own blurred material behind a transparent window, so your desktop shows through the app the way it does through System Settings — not a picture of blur, the real thing, updating as what is behind it moves. A new Glass section on General holds two controls: Liquid Glass, which turns it on and off, and Glass tint, which sets how dark the glass is, from Clear to Dark. Turning Liquid Glass off gives the solid dark window 1.9.0 had, and that is also what Windows and Linux get: the material is a macOS API, and no attempt is made to fake it elsewhere.

The rows and cards inside the window are glass too, and much clearer than they were. Their fill was measured off a reference the owner supplied rather than chosen by eye: each card now sits 0.020 white over what is behind it, against the reference's own 0.015 to 0.054, and the shadow that used to hang under every card is gone — three of the reference's four cards have none, and a shadow is what made them read as slabs floating above the window rather than as part of it. The card border is unchanged at 0.15; the reference measures 0.149, so it was already right.

Two things that were painted on top of the glass have been removed. Three wide sky-blue fields were being drawn over the real material, which is what made the window read as droplets rather than as a pane; they now appear only when Liquid Glass is off, where they are the opaque window's atmosphere and belong. The wide blue halo behind your account picture is gone as well.

Verified by photographing the running window over a flat neutral desktop, which is the only way to tell the app's own painting from the desktop showing through: with the glass on, the window's empty field is perfectly flat and the cards sit inside the reference's own range; with it off, the atmosphere returns as designed. Fixes a bug that could leave your Minecraft unable to start. If you installed the mod pack by hand before pointing Corvus at the folder — which the guide tells you is fine — the first update added the new mod files but could not remove the old ones, because it had no record of what was already there. Two copies of the same mod stops the game loading. Corvus now recognises the pack's own files by name, so superseded ones are removed whether or not it has a record, and it checks afterwards that only one copy of each mod is left. Your own mods are never touched: only files matching the pack's exact naming are removed, everything is backed up first, and each removal is written to the log.

Corvus can now update itself. From this version on you should not need to visit this site again: when a new Corvus is released it downloads it, checks it against the SHA-256 published here, replaces itself and reopens. It always asks first, even with automatic updates turned on — restarting the app while you are using it is not something it should decide on its own. If anything goes wrong the previous version is put back automatically: the new build has to actually start before the old one is discarded. Two honest limitations. On Linux the .deb needs administrator rights that Corvus cannot request, so it downloads and verifies the file and then shows you the exact command to run — it does not pretend to have installed it. On Windows the update reinstalls the MSI, which means Windows will show its usual permission prompt. This release also follows the site to its new address; if you are on 1.4.0 or earlier you need to download once from here by hand, because those versions are still looking for the old address and cannot be reached.
