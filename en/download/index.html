Native installers (no Java required)

These install like a normal desktop app and do not need Java installed separately. They are not code-signed yet, so your OS will show a first-run warning: on macOS, right-click the app and choose Open; on Windows, click "More info" then "Run anyway".

ASTRAEA's service has ended

ASTRAEA ended its service on 16 October 2026. Thank you to everyone who played it, from V1.0 to the final release, V1.5.4 "Defence".

Thank you, too, to everyone who told us about its bugs. It meant a great deal to see the blast doors and locks, the celestial blade and tools, and machines the size of buildings standing in your worlds.

What happens now

  1. In Corvus Store, ASTRAEA is archived and can no longer be installed.
  2. Corvus Agent disables and removes ASTRAEA from servers automatically, after taking a world backup, on its first sync on or after 23 October 2026.
  3. Its download is no longer offered on this site. The pages stay up as a record of ASTRAEA.

Please read this

When ASTRAEA is removed, its blocks and items disappear from your worlds. Back up any world you want to keep before 23 October 2026.

OUKA is not affected.

Thank you, all of you, for everything.

Aureum (lightweight optimisation mod, separate download)

Aureum is a separate, independent mod. It optimises game logic, memory, and server tick cost, and deliberately never touches the chunk-render pipeline. It is not a replacement for Sodium — it optimises the side Sodium does not touch, so it is safe to run alongside it. If you want higher FPS, install Sodium separately.

Download Aureum

Measured so far: -6.3 MB at 2,209 loaded chunks, -17.2 MB after generating a similarly sized area of new terrain (both reproduced across two independent runs). MSPT (tick time) is unchanged within measurement noise. Two client-side toggles (particle limit, block-entity render distance) ship off by default and unmeasured, because this development environment has no client. See the README on GitHub for installation and configuration. Aureum 2.0.0 adds one more, found by profiling allocations: the server's random-tick loop now creates about 98% fewer coordinate objects (about 1.3 GB down to about 0.02 GB over a 9,600-tick benchmark; a JFR estimate, two on/off pairs agree). No change in tick time or heap is claimed.

Corvus Agent

A program for the Minecraft server you host yourself: it keeps the server's mods in step with Corvus Store. It checks each download, stops the server, swaps the files, starts it again, and puts the old files back if it does not come up.
