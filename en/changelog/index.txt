31:T433,Corvus Agent is the small program that sits beside a Minecraft server you host yourself and keeps its mods in step with the Store. Until now it was a zip from the website and a command typed in a terminal. It is now the last entry on the Store's shelf. Press GET and choose your server folder: the Store downloads the agent, checks its size and SHA-256 against the site, puts it in that folder as corvus-agent.jar, and writes its configuration and two start scripts (start-with-corvus.bat, and .sh for Linux and macOS). It looks in the folder's mods and lists the Corvus mods it finds there, and it reads your server's own start command from the .bat or .sh you already use, so there is nothing to edit by hand. From then on you start the server with start-with-corvus: the agent checks for updates before the server starts and every ten minutes while it runs, stops the server with its own "stop" command when nobody is online, swaps the mods, starts it again, and puts the old files back if it does not come up.
