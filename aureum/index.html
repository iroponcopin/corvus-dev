Aureum(軽量化MOD・別配布)

Aureum は独立した MOD です。ゲームの処理・メモリ・サーバーのティックの負荷を軽くしますが、チャンクの描画には決して触れません。Sodium の代わりではなく、Sodium が触らない側を軽くするので、並べて使えます。FPS を上げたいなら Sodium を別に入れてください。

現在の実測は2,209チャンク読み込み時に -6.3 MB、同規模の新規生成で -17.2 MB(いずれも独立2回計測で一致)。MSPT(tick時間)への影響は計測範囲内で変化なしです。クライアント側の2機能(パーティクル上限・ブロックエンティティ描画距離)は既定offで、この開発環境にクライアントが無いため未計測です。導入・設定方法はGitHubのREADMEを参照してください。 Aureum 2.0.0 では、アロケーションの計測で見つけた最適化を1つ追加しました。サーバーのランダムティック処理が作る座標オブジェクトが約98%減ります(9,600 tick のベンチで約1.3 GB → 約0.02 GB。JFRによる推計で、有効・無効の2組で一致)。tick時間とヒープが変わるとは主張しません。

最適化はすべて個別にオフにできる

config/aureum.json の各設定キーは1つずつ独立してオフにできます。オフにすると、その機能に関するAureumのバイトコード変更は一切適用されません — 他のMODと衝突した場合に取れる、最も確実な切り分け手段です。

動作要件

  • Minecraft 26.3 (Fabric)
  • Fabric Loader 0.19.5+
  • Fabric API
  • Java 25+
